# PANTH_misinformation_nudge
Prototype of PANTH system design to nudge vaccine misinformation sharing hesitancy
PANTH — Platform for Automated Nudging of Truth and Harm
Proof-of-concept prototype for the paper "Stop, Think and Share" (ISR submission ISRE-2025-2523). Displays a Truth-O-Meter and Harm-O-Meter for vaccine misinformation claims using the Anthropic Claude API.
Live demo: [your Vercel/GitHub Pages URL]
Usage: Open index.html in a browser, or visit the live URL. Enter your Anthropic API key in the Analyser tab to score custom claims.
